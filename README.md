# Roadmap de Engenharia de Dados

Material gratuito do QG da Engenharia de Dados. Você recebeu porque comentou **ROADMAP**.

## Como usar este material

1. Abra o arquivo [roadmap-engenharia-de-dados.pdf](roadmap-engenharia-de-dados.pdf) → clique em **Download** se quiser guardar
2. Descubra em qual fase você está
3. Copie o checklist abaixo e marque o que já domina

## A trilha

Fase 1 Base → Fase 2 Pipelines → Fase 3 Cloud e escala → Fase 4 Arquitetura

## Checklist

**Fase 1: Base**
- [ ] SQL: SELECT, JOIN, GROUP BY, window functions
- [ ] Python: funções, arquivos, pandas
- [ ] Git e GitHub
- [ ] Modelagem relacional

**Fase 2: Pipelines**
- [ ] ETL e ELT
- [ ] Consumo de APIs
- [ ] Docker
- [ ] Airflow
- [ ] dbt
- [ ] Modelagem dimensional

**Fase 3: Cloud e escala**
- [ ] Uma nuvem a fundo
- [ ] PySpark
- [ ] Data lake e Lakehouse
- [ ] Databricks
- [ ] Kafka

**Fase 4: Arquitetura**
- [ ] Lambda, Kappa, Medallion
- [ ] Data Mesh e governança
- [ ] Custo e observabilidade
